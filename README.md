# Hybrid Infrastructure Platform

[![My Homelab](./Hudater_Homelab_v1.0.svg)](https://blog.hudater.dev/posts/homelab/)

Hybrid platform integrating **on-prem virtualization** with **cloud networking and automation**.

Core capabilities:

- Proxmox virtualization platform
- Infrastructure provisioning via **OpenTofu / Terraform**
- Configuration management using **Ansible**
- Multi-tenant ingress using **Traefik**
- Identity and authentication with **Keycloak + OpenID**
- DNS stack using **Unbound**
- Private networking via **WireGuard + Tailscale**
- Observability stack with **Prometheus, Loki and Grafana**

Full architecture breakdown and diagrams → https://blog.hudater.dev/posts/homelab/
